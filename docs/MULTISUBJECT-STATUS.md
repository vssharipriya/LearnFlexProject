# CBSE-only curriculum status

- Board selection/content is CBSE only.
- Classes 6–10 are represented.
- NCERT chapter catalogues are mapped for the listed subjects and editions.
- CBSE curricular areas (Arts, PE, Vocational, CT/AI and the Class IX Individuals in Society area) are shown as activity modules, not textbook chapters.
- Each module has 20 original questions across four adaptive levels.
- Teacher review is required for chapter mapping, school subject combinations, lesson explanations and answer keys.
