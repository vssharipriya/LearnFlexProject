# CBSE curriculum scope — 2026–27

The active board in this release is **CBSE only**. No other board curriculum is included in the active app.

The textbook catalogue covers the available NCERT chapters for Mathematics, Science, Social Studies and the listed language choices in Classes 6–10. Classes 6–9 use the available 2026–27 NCERT editions where listed; Class 10 uses the continuing-cohort textbook/course provisions where applicable.

CBSE's 2026–27 secondary curriculum identifies language choices, Mathematics, Science, Social Science and curricular/optional areas. For Class IX, the 2026–27 scheme includes the new scheme-of-studies areas, including Vocational Education, Individuals in Society, Art Education, Physical Education and Well-being, and CT/AI modules. Middle-stage CT/AI learning modules are included as curricular activities. These activity modules are not falsely presented as official textbook chapter titles.

Every module has 20 original practice questions (5 each at foundation, reinforcement, standard and challenge levels). They are not copied official exam questions.
