
# LearnFlex 📚

### Making learning easier, smarter, and more personal.

LearnFlex is a web-based learning platform built to help students learn at their own pace. It brings together NCERT-based subjects, chapter-wise learning, practice questions, and adaptive learning features in one place.

The idea behind LearnFlex is simple: every student learns differently, so learning should be flexible enough to support individual needs.

The platform is designed around students from Classes 6 to 10, with a focus on making everyday learning and practice more organized and engaging.

## ✨ What LearnFlex offers

- **NCERT-based learning:** Subjects and chapters organized for Classes 6–10.
- **Chapter-wise practice:** Questions to help students revise and understand individual topics.
- **Adaptive learning:** Learning experiences that respond to student performance.
- **Student dashboard:** A place for students to access their learning activities.
- **Teacher features:** Tools designed to support teaching and student learning.
- **Offline support:** Includes functionality to support access when connectivity is limited.
- **Responsive design:** Designed to work across different screen sizes.

##  Running the Project Locally

To run LearnFlex on your computer:

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Open the project folder**

```bash
cd LearnFlex
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the application**

```bash
npm start
```

**5. Open it in your browser**

```text
http://localhost:3000
```

*Note: The start command and port depend on the configuration in package.json and server.js.*

##  Deployment

LearnFlex includes a Dockerfile and Render configuration to support cloud deployment.

The application can be deployed through Render after connecting the GitHub repository and configuring the required environment variables and database settings.

##  Why LearnFlex?

Learning shouldn't be limited to reading textbooks or solving the same type of questions repeatedly.

LearnFlex aims to make the process more interactive by bringing learning materials, practice, and adaptive experiences together. The goal is to help students understand concepts better and become more confident learners.
